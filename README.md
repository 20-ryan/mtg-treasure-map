# MTG Card Compass

Build a modern mobile app called "MTG Store Finder". The app helps Magic: The Gathering players find specific cards, booster packs, commander decks, and accessories sold by local game stores. Include a searchable card database, an interactive map with nearby stores using geolocation, real-time inventory status, price comparison, store profiles, directions via maps, wishlist with restock notifications, and filtering by distance, price, product type, and availability. Use a clean dark fantasy-inspired interface with MTG-style colors (black, gold, purple, and blue), card images, responsive layouts, and smooth navigation. The home page should feature a search bar, featured sets, and nearby stores. The app should feel fast, modern, and easy for both casual and competitive MTG players.
